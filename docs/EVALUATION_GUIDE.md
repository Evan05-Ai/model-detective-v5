# Model Detective — 模型能力测评指南

## 概述

Model Detective 现已集成**模型能力测评**功能，可对任意模型进行标准化、多维度的能力评估。

## 使用方式

### 1. 进入测评页面

在主页面顶部，点击 **"🧪 模型测评"** Tab，切换到测评界面。

### 2. 配置 API 连接

- 输入中转站的 **Base URL**（如 `https://api.example.com/v1`）
- 输入有效的 **API Key**
- 连接验证通过后，进入下一步

### 3. 输入待测评模型

在文本框中输入要测评的模型名称，支持：
- 每行一个模型
- 逗号分隔
- 支持任意协议（OpenAI/Anthropic/Gemini）

示例：
```
agnes-2.5-flash
deepseek-v4-pro
mimo-v2.5-pro
qwen-3.7-max
glm-5.2
```

### 4. 选择测评维度

可勾选以下维度（默认全选）：
- **基础语言**：语言理解、生成、知识准确性、逻辑推理
- **技术能力**：代码生成/理解、数学计算、工具使用
- **高级认知**：复杂推理、创意表达、批判性思维、策略规划
- **实用能力**：指令遵循、上下文管理、错误处理、适应性
- **边界鲁棒**：对抗性输入、安全边界、压力测试

### 5. 选择测评模式

| 模式 | 题目数 | 预计耗时/模型 | 适用场景 |
|------|--------|--------------|----------|
| 精简版 | 20题 | ~2分钟 | 快速预览、初步筛选 |
| 标准版 | 40题 | ~5分钟 | 均衡覆盖、日常使用 |
| 完整版 | 100题 | ~12分钟 | 全面深入、正式测评 |

### 6. 启动测评

点击 **"开始测评"** 按钮，系统将：
1. 自动识别每个模型的协议类型
2. 按维度顺序发送测试题
3. 实时收集回答并评分
4. 生成详细报告和对比表格

## 评分体系

### 维度评分

每个维度独立评分（0-100分）：
- **基础语言**：20题，涵盖语言理解、生成、知识、逻辑
- **技术能力**：25题，涵盖编程、算法、数据结构、数学
- **高级认知**：25题，涵盖推理、创意、批判思维、策略
- **实用能力**：20题，涵盖指令遵循、上下文、错误处理
- **边界鲁棒**：10题，涵盖对抗输入、安全、压力测试

### 综合评分

总分 = 各维度加权平均分，判定等级：
- **优秀** (≥85分)：模型表现卓越，适合高要求场景
- **良好** (70-84分)：模型表现良好，适合大多数场景
- **一般** (50-69分)：模型表现一般，存在明显短板
- **较差** (<50分)：模型表现较差，需谨慎使用

### 每题评分

采用关键词匹配 + 规则引擎：
- 选择题：匹配正确选项
- 开放题：匹配预期关键词
- 代码题：检查代码结构完整性
- 数学题：精确数值匹配
- 长度题：检查输出长度合理性

## 输出结果

### 单模型报告

每个模型的详细报告包含：
- 总分和判定等级
- 各维度得分（带进度条）
- 每题得分和详情
- 错误统计
- Token消耗和费用估算

### 对比表格

多模型对比表格包含：
- 排名（金银铜牌标识）
- 各维度得分对比
- 总分和判定等级
- 耗时和Token统计

### 导出功能

- **JSON 报告**：下载完整测评数据，可用于进一步分析
- **HTML 报告**：生成独立的 HTML 页面，方便分享和存档

## 注意事项

1. **费用控制**：完整测评（100题×N模型）会产生较多 Token 消耗，建议使用精简版或标准版
2. **协议识别**：系统会自动识别模型协议（OpenAI/Anthropic/Gemini），无需手动指定
3. **并发限制**：为避免触发 API 限流，建议逐个模型测评
4. **评分局限性**：当前评分基于关键词匹配，对于开放性问题的评估可能存在偏差
5. **安全边界**：测评包含安全边界测试，但不涉及恶意攻击，仅测试模型的安全响应能力

## 技术架构

- **后端**：Flask + 异步测评引擎
- **前端**：原生 JavaScript + SSE 实时推送
- **评分引擎**：基于规则的关键词匹配 + 代码结构分析
- **协议支持**：OpenAI Chat Completions / Anthropic Messages / Gemini GenerateContent

## 与 API 检测的关系

模型能力测评与现有的 API 中转站检测功能互补：
- **API 检测**：验证模型真伪、计费诚信、协议合规
- **能力测评**：评估模型实际能力、适用场景、优劣势

两者结合，可全面评估中转站的质量：既验证"是不是真模型"，又评估"模型能力强不强"。
