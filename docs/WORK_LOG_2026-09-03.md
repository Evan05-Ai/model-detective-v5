### 2. Cloudflare 隧道凭证轮换 ✅（用户授权浏览器 + 三次 UAC）

**背景**：旧隧道凭证 `.cloudflared/model-detective.json` 随 commit `9cbb8dc` 推送进公开仓库（origin/master 顶端仍存在），隧道 UUID 可经 DNS CNAME 公开获取——拿到 UUID+Secret 者可自建 connector 接入隧道截流（站点业务就是收集用户中转站 Key，风险实打实）。

**执行过程（零停机）**：
1. `cloudflared tunnel login` 浏览器重新授权（本机 cert.pem 此前缺失）
2. 创建新隧道 **model-detective-v2**（UUID `3afd1108-3572-4fbe-b841-b5f7cd9d23fa`）
3. 临时 connector（用户会话后台进程）先行连入新隧道
4. `tunnel route dns --overwrite-dns` 切换 CNAME，公网验证 200
5. Windows 服务 **Cloudflared** 改为本地配置模式（注册表直写 ImagePath）并重启
6. 停临时 connector → 服务成唯一承载方 → **删除旧隧道 model-detective（fd06a112）→ 旧泄露 Secret 永久失效**
7. 清理：`C:\ProgramData\cloudflared\token`（含旧 Secret）、项目内旧凭证 json、token 副本全部删除

**踩坑记录（4 条，详见 MEMORY.md 同名章节）**：
1. `--config` 必须放在 `tunnel` 后 `run` 前（`tunnel run --config x` 直接报 flag undefined）
2. sc.exe binPath= 传内嵌引号会**静默失败**——必须 Set-ItemProperty 直写注册表 ImagePath
3. PowerShell 5.1 按 ANSI 读 .ps1，提权脚本含中文路径必乱码（`Ai工作`→`Ai宸ヤ綔`，曾致服务 1067 崩溃）——服务参数一律纯 ASCII 路径（`C:\Users\evanc\.cloudflared\config-v2.yml`）
4. 本机 curl 验证公网会被 v2rayN/mitmproxy 间歇吞包（整 10 秒黑洞，连 github.com 也可能超时）——**验证站点必须用外部视角**（WebFetch/手机流量）
