**遇到的问题与解决**：

1. **cloudflared 登录证书下载失败**
   - 现象：`cloudflared tunnel login` 无法自动下载 cert.pem
   - 解决：改用 `cloudflared service install <token>` 方式，从 Cloudflare Dashboard 获取 Token

2. **凭证文件路径问题**
   - 现象：`Failed to get tunnel` 错误
   - 解决：修正 `config.yml` 中 `credentials-file` 路径为项目目录绝对路径

3. **服务安装权限问题**
   - 现象：`Access is denied` 错误
   - 解决：确保以管理员身份运行 PowerShell
